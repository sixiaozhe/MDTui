# 使用手册

`mdtui PAGE.md` 启动工作台；SSH 必须分配终端，例如先 `ssh -t device`。`mdtui check PAGE.md` 可以在非终端环境校验配置。

支持 `--help`、`--version`、`--no-color`、`--log-file PATH`；也遵循 `NO_COLOR`。日志默认关闭，显式开启仅记录面板 ID、请求/generation、状态、耗时，不记录参数、输出和环境。

## 交互

| 键 | 行为 |
|---|---|
| Tab / Shift+Tab | 说明区、输入、面板之间切换 |
| ↑↓ / Enter | 列表光标移动 / 确认选择；带 `open` 的列表按 Enter 进入子页，仅移动不会查询 |
| Enter / Esc | 输入开始编辑或提交 / 放弃草稿；输入中 q 和动作键都是文字 |
| PgUp / PgDn / Home / End | 翻页、首尾；End 恢复日志跟随 |
| ←→ | 横向滚动长代码或宽表 |
| /，n，N | 搜索当前说明区或面板；下一个、上一个匹配 |
| F2 | 动作菜单 |
| 大写 `Z` / Esc | 放大当前面板 / 退出放大；放大时 Tab 切换面板 |
| `[` / `]` | 切换工作区详情视图 |
| ? / ! | 帮助 / 当前面板错误详情 |
| Space | 暂停或恢复日志跟随，进程继续读取 |
| Ctrl+C | 取消当前任务，无任务时提示 q 退出 |
| q | 子页返回上一层；根页退出，终止受管进程并恢复终端 |

子页内 Esc 或 q 返回上一层；根页 q 退出。

确认框默认选择取消，Tab 或左右键切换到执行，再 Enter。Esc 总是关闭弹窗。弹窗优先于页面快捷键。

输入编辑时，左右键按完整字符簇移动光标，Home/End 跳到首尾，Backspace/Delete 删除光标两侧内容；长值会自动滚动以保持光标可见。输入中的 `/`、`n`、`N` 均作为普通文字。搜索时输入词语后按 Enter，Esc 放弃；空查询会清除旧搜索。匹配文字高亮，当前匹配行以粗竖线标示。搜索仅作用于当前焦点区域。

`blocked` 表示需选择对象或提交必填输入；`idle` 等待动作；`queued/running` 排队/执行；`ready/error/cancelled` 成功/失败/取消。查询错误保留同一对象上次成功数据并标记“过期”；切换对象清空旧数据。错误状态显示连续失败次数，`!` 查看程序、退出码、耗时和 stderr。

刷新间隔从完成时开始计时，不发生重叠。连续刷新合并为最多一次后续查询。stream 共同占用并发额度，同时最多一个；至少要设置两个槽位，让普通查询继续运行。

主从页面在 100 列以上分栏；工作区页面在宽终端保留左侧列表，选中对象后自动打开相关详情。窄工作区显示当前焦点面板，`[` / `]` 可切换详情。高度不足时显示当前面板，Tab 切换。小于 60×16 提示调整尺寸，仍可 q 退出。说明区可独立滚动，多个输入逐个聚焦编辑。

Markdown 会按终端能力渲染标题层级、粗体、斜体、删除线、引用、嵌套列表、任务项、代码、链接、图片替代文字和 GFM 表格。普通正文按区域宽度自动换行；宽表与长代码保持原行，可用左右键查看。每个面板底边显示当前位置，长内容右边框显示滚动标记，底部显示当前焦点和可用操作。命令输出中的控制序列会先被过滤，颜色和排版只来自 MDTUI 自身；`--no-color` 会关闭颜色，同时保留边框与文字层级。

## 故障恢复

普通退出、SIGINT/SIGTERM 和可恢复 panic 执行清理。SIGKILL/断电无法执行清理，必要时在 shell 输入 `stty sane; reset`。主动 daemonize 或脱离进程组的子进程不属于完整清理保证；不要把此类工具直接作为面板命令。

退出码：0 正常退出/校验通过，2 配置/参数错误，3 终端初始化失败，1 其他启动/内部错误。某个面板失败不会改变正常退出码。
