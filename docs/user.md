# 使用手册

`mdtui PAGE.md` 启动工作台。它运行在 Linux 设备上，通过普通 SSH PTY 使用；目标机器不需要 Go、Python 或其他运行时。

## 低资源设备

```sh
./bin/mdtui --low-resource examples/ops/index.md
./bin/mdtui --stream-buffer-kib 512 --stream-interval 500ms PAGE.md
```

`--low-resource` 将日志窗口设为 256 KiB / 2000 行，文本日志每 500ms、Markdown 日志每 1s 更新一次；按键和命令结束事件即时处理。暂停的每个父页保留最多约 1 MiB 的原始面板文本，超出预算的整块文本会释放并显示提示，列表、选择和参数保留。返回后按页面原有恢复规则调度；缓存释放本身不会自动重跑命令，尤其不会重跑一次性变更操作。

`--stream-buffer-kib` 支持 64..2048 KiB，`--stream-interval` 支持 100ms..5s，显式参数覆盖低资源预设中的相应值。普通模式默认保留 2 MiB / 10000 行，文本每 100ms、Markdown 最快每 500ms 更新；低资源模式的 Markdown 最快每 1s 更新。所有限制和更新设置会传给子页；命令的 `refresh` 周期、超时和并发配置保持页面定义。窗口满时从最旧完整行淘汰，暂停跟随仍继续收集到有界窗口，导出仅包含已发布的窗口。详细测试方法见[性能说明](performance.md)。

## 快速开始

在构建机或设备上准备二进制：

```sh
bash scripts/build.sh
./bin/mdtui check examples/linux-workbench.md
./bin/mdtui examples/linux-workbench.md
```

通过 SSH 使用时必须分配 PTY：

```sh
ssh -t user@device
./mdtui PAGE.md
```

没有交互终端时运行会被拒绝，此时请使用：

```sh
mdtui check PAGE.md
```

`check` 只解析和校验页面，不执行任何命令；它会递归检查子页、引用、循环和深度限制。配置检查通过不代表目标命令已经安装或具备权限。

## 命令行

| 用法 | 说明 |
|---|---|
| `mdtui PAGE.md` | 打开工作台，需要可交互 TTY |
| `mdtui check PAGE.md` | 校验页面及子页，不执行命令 |
| `mdtui --no-color PAGE.md` | 关闭颜色，保留边框和文字层级 |
| `mdtui --no-mouse PAGE.md` | 关闭鼠标接管，使用键盘和终端原生选择/复制 |
| `mdtui --log-file PATH PAGE.md` | 写入调试日志；只记录 ID、状态和耗时，不记录参数与输出 |
| `mdtui --version` | 显示版本 |
| `mdtui --help` | 显示简要帮助 |

也支持 `NO_COLOR` 环境变量。退出码：`0` 正常退出或校验通过，`2` 页面/参数错误，`3` 终端初始化失败，`1` 其他启动或内部错误。单个面板命令失败不会改变工作台正常退出码。

## 界面与焦点

页面由四部分组成：

- 顶部：页面标题、页面 ID 和普通 Markdown 说明区
- 参数区：页面声明的输入控件
- 面板区：列表、详情、日志等命令结果
- 底部：当前状态、提示和快捷键

`Tab` / `Shift+Tab` 在说明区、输入和面板之间切换焦点。焦点决定键盘操作作用于哪个区域；它本身不会执行命令。

列表有三层不同状态：

| 状态 | 操作 | 含义 |
|---|---|---|
| 焦点 | `Tab` / `Shift+Tab` | 键盘当前作用于这个列表 |
| 光标/高亮 | `↑` / `↓`、`PgUp` / `PgDn`、`Home` / `End` | 当前指向的选项 |
| 选中 | `Enter` | 已确认的对象，会驱动依赖它的查询 |

默认只移动光标不会查询。页面配置 `on_focus` 后，光标项变化（包括列表首次获得焦点后的首项）会执行预览动作；按 `Enter` 确认后才触发 `on_select` 或依赖 `selected.id` 的查询。

## 列表、选择与联动

- `↑` / `↓`：移动列表光标
- `PgUp` / `PgDn`：按页移动
- `Home` / `End`：跳到首项/末项
- `Enter`：确认当前光标项

确认选择后：

- 引用 `<列表ID>.selected.id` 的面板会重新查询
- 配置了 `on_select` 的列表会执行对应动作
- 配置了 `open` 的列表会进入子页
- 依赖链上的旧请求会被取消，旧结果不会覆盖新状态

如果页面使用 `on_focus` 做预览，光标移动时只执行预览面板；按 `Enter` 后才执行完整查询。示例见 [inspection.md](../examples/inspection.md)。

## 子页导航

列表可以进入全屏子页：

- 在带 `open` 的列表上按 `Enter` 进入子页
- 子页内按 `Esc` 或 `q` 返回上一层
- 根页面按 `q` 退出工作台
- 父页会暂停定时刷新和流式任务，并保留选择、滚动、焦点和已有结果；返回后恢复
- 支持最多 8 层；循环引用会在 `check` 和运行时被拒绝

`open` 可以是一个固定子页，也可以按选项映射到不同子页：

```yaml
open:
  system: ./navigation-system.md
  network: ./navigation-network.md
```

未映射的选项不会跳转，底部会显示提示。子页声明 `parent: 列表ID` 后，可用 `{ref: "parent.selected.id"}` 读取打开它时的父页选中对象。

## 输入

- `Enter`：开始编辑；编辑中再次按 `Enter` 提交
- `Esc`：放弃本次编辑
- `←` / `→`：按完整字符簇移动光标
- `Home` / `End`：跳到行首/行尾
- `Backspace` / `Delete`：删除光标两侧内容

编辑草稿与已提交值分开。输入中的 `q`、`/`、`n` 和动作键都作为普通文字，不会触发页面快捷键。必填输入为空时，依赖它的面板显示 `blocked`，不会传入空值。

## 动作

按 `F2` 打开页面动作菜单；页面也可以为动作绑定单个小写字母快捷键。

- 动作菜单和确认框优先于页面快捷键
- 确认框默认选中“取消”，`Tab` 或左右键切换，`Enter` 执行
- `run` 执行一次目标面板，不会启动周期重试
- `refresh` 只刷新 snapshot 面板，可一次刷新多个目标
- 动作也可以由 `on_focus` / `on_select` 自动触发；自动触发的动作不显示确认框

对会改变设备状态的命令，页面作者应配置非空 `confirm`。

## 刷新、流式日志与并发

- snapshot 面板可以设置 `refresh`，从上次完成后开始计时，不会重叠执行
- 连续刷新会合并为最多一次后续查询
- `Space` 暂停或恢复日志跟随，进程继续读取
- `End` 在流式面板中恢复跟随
- 同时最多运行一个 stream；页面应设置 `max_parallel` 至少为 2，给普通查询保留槽位
- 切换对象、输入变化或进入子页会取消旧请求，过期结果不会写入当前状态

## 布局与窄终端

支持三种布局：

- `stack`：面板按声明顺序纵向排列
- `master-detail`：宽度至少 100 列时左侧显示 sidebar，右侧纵向排列其他面板
- `workspace`：宽度至少 90 列时左侧显示 sidebar，右侧一次显示一个详情面板；`[` / `]` 切换详情

`Tab` 切换焦点，`Z` 放大当前面板，放大时 `Tab` 切换面板，`Esc` 退出放大。

`master-detail` 在宽度不足 100 列时退化为 stack；`workspace` 在窄终端只显示当前焦点面板。高度不足时只显示当前面板并标注索引。小于 60×16 时显示尺寸不足提示，仍可按 `q` 安全退出。

## 搜索与 Markdown

- `/`：搜索当前焦点区域
- `Enter`：执行搜索
- `n` / `N`：下一个/上一个匹配
- `Esc`：取消搜索
- 空查询：清除旧搜索

匹配文字高亮，当前匹配行用粗竖线标示。搜索只作用于当前区域，不跨面板。

Markdown 支持标题层级、段落、列表、任务项、引用、强调、代码块、链接地址和 GFM 表格。普通正文自动换行；代码块和表格保持原行，可用左右键横向查看。HTML 和图片不会执行或加载，图片显示替代文字。命令输出中的控制序列会先被过滤，不会破坏终端。

## 状态与错误

| 状态 | 含义 |
|---|---|
| `idle` | 尚未执行，等待动作或选择 |
| `queued` | 已排队 |
| `running` | 正在执行 |
| `ready` | 最近一次执行成功 |
| `blocked` | 缺少选择或必填输入 |
| `error` | 命令失败或超时 |
| `cancelled` | 用户取消 |

错误会保留同一对象上次成功的数据并标记“过期”；切换对象会清空旧数据。错误状态显示连续失败次数，按 `!` 查看程序名、退出码、耗时和 stderr。

## 故障恢复与安全

普通退出、SIGINT/SIGTERM 和可恢复 panic 会清理受管进程并恢复终端。SIGKILL、断电或主动 daemonize 的子进程无法保证清理；必要时在 shell 执行：

```sh
stty sane; reset
```

页面可以执行本机程序，请只运行可信来源的页面。命令以参数数组启动，不经过 shell 拼接；`check` 不会执行页面命令。不要把需要交互输入的完整终端程序直接作为面板命令。

## 面板高度

页面作者可以给 panel 设置 `max_height`，单位为终端行数，包含上下边框，最小 3 行；省略时自动分配。高度上限适用于堆叠、主从、工作区和放大视图。终端空间不足时可能显示得更小；内容超出时可以用 ↑↓、PgUp/PgDn 或滚轮查看，End 跳到末尾。面板高度只影响显示，不裁剪采集结果或导出内容。

运行 `./bin/mdtui examples/panel-height.md`，可以对比最多 5 行的概览、最多 6 行的接口列表和占用剩余高度的日志。

## 鼠标操作

支持鼠标上报的终端默认启用鼠标；经 SSH 使用时仍需分配 PTY。终端没有上报鼠标事件时，继续使用键盘操作。无需修改页面配置。

| 区域 | 鼠标操作 |
|---|---|
| 列表 | 单击定位光标；同一项在 400ms 内双击等同 Enter，确认选择或进入子页 |
| 说明、详情、日志 | 单击聚焦；滚轮滚动指针所在区域，滚动日志会暂停跟随 |
| 工作区详情标签 | 点击切换详情面板 |
| 子页顶部“‹ 返回” | 点击返回上一层 |
| 开关 / 下拉框 | 点击开关切换；点击下拉框打开，再点击选项确认 |
| 文字 / 数字参数 | 点击开始编辑，键盘输入并按 Enter 提交或 Esc 放弃；数字编辑时滚轮按 1 调整 |
| 参数栏 / 操作栏 | 点击两端 ‹ / › 或使用滚轮，切换显示的参数或按钮 |
| 按钮 | 点击方括号内的按钮激活动作；依赖禁用和确认流程保持生效 |
| 动作菜单 / 弹窗 | 点击菜单项执行，点击“取消”或“执行”操作确认框，点击右上角关闭；滚轮浏览内容或选项 |

编辑草稿、搜索或过滤输入尚未提交时，点击其他区域不会丢弃草稿或执行动作；请先 Enter 提交或 Esc 取消。单击列表只定位，不确认选择，但页面配置的 on_focus 预览动作仍会照常触发。弹窗会遮挡下方控件，点击弹窗外不会操作下方页面。当前不提供拖动布局、应用内拖选文字或右键菜单。

需要终端原生文本选择和复制时，运行 `./bin/mdtui --no-mouse examples/controls.md`。退出程序时会关闭鼠标上报并恢复终端。

## 表单控件

运行 `./bin/mdtui examples/controls.md` 体验开关、下拉框、数字和按钮。普通焦点顺序为说明区、参数、面板、操作按钮，使用 Tab / Shift+Tab 循环切换。参数栏一次显示当前参数；操作栏一次显示当前按钮及序号，聚焦后按 Enter 执行。

- 开关：Space 或 Enter 切换，显示开启/关闭，命令接收字符串 true/false。
- 下拉框：Enter 打开，↑↓ 或 Home/End 移动，Enter 确认、Esc 放弃。命令接收选项值，界面显示标签。
- 数字：Enter 编辑，↑↓ 按 1 调整，Enter 提交、Esc 放弃。仅支持整数；越界或无效输入会显示错误并保留草稿，清空 required 数字会阻止依赖命令执行。
- 按钮：Enter 激活对应动作；有确认框时默认取消，用 Tab 切换到执行后 Enter 确认。缺少依赖时按钮显示禁用原因。

旧页面的文本输入和动作快捷键保持原有行为。F4 导出也会记录新控件的已提交值。

## 导航上下文、列表过滤与诊断导出

页面顶部显示从根页到当前页的导航路径；子页同时显示打开它时的父页对象 ID。

多层导航可运行 `./bin/mdtui examples/multilevel.md`，按“设备 → 接口 → 诊断”逐级 Enter 进入，Esc / q 每次返回一层；根页 q 退出。上层页面进入暂停状态，返回时恢复参数、焦点、选择、过滤条件及已有结果。返回后再次 Enter 可重新进入同一项；新打开的子页重新加载，已关闭子页的输入和执行结果不会跨次保留。第三层及更深页面的路径会标注中间层的父页对象 ID，便于区分设备上下文。页面数量限制为 256，含根页最多 8 层。

聚焦 `items-json` 列表后按 `F3`，输入过滤词并按 Enter 应用。过滤按 ID、标签和描述进行不区分大小写的子串匹配。再次按 F3，删除全部文字后按 Enter 清除过滤；Esc 放弃本次编辑。过滤只隐藏不匹配的行，不改变原始结果或已确认的选择；没有匹配项时 Enter 不执行选择。↑↓、Home、End 和搜索在可见项目中移动，Enter 确认可见项目的原始 ID。列表刷新会继续应用过滤，并尽量保持光标所在对象的 ID；从子页返回后保留父页过滤条件。

按 `F4` 将当前页导出为 `mdtui-report-时间-随机后缀.md`，保存在启动 MDTUI 时的工作目录中。弹窗显示导出的完整绝对路径或失败原因，按 Enter 或 Esc 关闭。每次导出创建独立文件，包含采集时间、导航路径、父页对象、当前参数、各面板的已有结果、状态、结果更新时间和错误输出。列表导出包含所有项目，包括被过滤隐藏的项目。流式面板导出当前保留的输出窗口及丢弃/截断计数；导出不启动新命令、不等待正在执行的任务，也不包含其他页面的面板结果。文件保留当前参数和命令输出，分享前请确认内容适合接收方。
