# 验证范围与已知边界

MDTUI 的自动化验证环境为 Ubuntu 22.04 / WSL2、Linux x86-64、UTF-8 终端。以下结果只适用于该参考环境；**真实嵌入式设备尚未验收**。目标设备的 CPU、内核、资源限制和常用 SSH 客户端仍需实测。

## 自动化覆盖

运行 `bash scripts/verify.sh` 会依次检查依赖摘要、运行 `go vet`、单元测试和竞态检测，构建程序，校验四个示例页面，并运行 CLI 与真实 Linux PTY 交互测试。PTY 场景覆盖列表选择、动作确认、输入编辑、搜索、窗口尺寸变化、信号退出和终端恢复；Linux 运维示例还覆盖主题选择和本机回环地址诊断。

| 范围 | 方法 | 当前结果 |
| --- | --- | --- |
| 页面编译 | 字段、引用、循环依赖、容量限制和惰性 `check` | 通过 |
| 调度与命令 | 稳定 ID、依赖失效、刷新合并、超时、进程组清理 | 通过 |
| 终端交互 | 模拟屏测试和真实 PTY 测试 | 通过 |
| Markdown | 富文本、正文换行、宽代码与表格横向查看、搜索 | 通过 |
| Linux 示例 | 六类任务菜单、参数校验和适配器的固定参数调用 | 通过 |
| 并发安全 | `go test -race ./...` | 通过 |
| 交叉构建 | ARM64、ARMv7、MIPS little-endian Linux | 构建通过，未在硬件执行 |

`bash scripts/cross-build.sh` 生成跨架构产物及 ELF/摘要记录。测试原始输出写入本地 `docs/evidence/`，其中可能包含执行机器信息，因此该目录不会进入公开仓库；任何人都可以用上述脚本重新生成。

## 性能观察

参考环境中，8 面板、一个持续约 2 MB/s 的 Markdown 日志流运行 30 分钟，RSS 峰值约 48.9 MiB，结束约 44.8 MiB；记录范围内未见单调增长。这不是所有页面、输出格式和设备均满足同样内存预算的保证。`tests/integration/performance.py` 可用于在目标设备上复测，另有 `tests/integration/latency.py` 测量本地 PTY 字节输出延迟。

## 使用边界

- MDTUI 只负责执行可信页面声明的本机程序。`check` 不运行命令；实际启动页面时，请先审查其 `exec` 和动作。
- Markdown 图片显示替代文字，HTML 作为文字呈现；它不是浏览器。终端小于 60×16 时显示尺寸提示。
- 输入是单行文本，多个输入依次聚焦；暂无页面热重载、输入历史或持久化。
- Linux 进程组用于清理子进程；主动脱离进程组的 daemon 不在清理保证内。
- `linux-tools` 的可用结果取决于发行版安装的命令和当前用户权限。连通性诊断会发送 ICMP 包，但不会修改系统配置。
- 静态截图和动图使用固定示例数据展示界面，不能作为真实设备截图或性能证据。
